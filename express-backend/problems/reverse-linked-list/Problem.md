## Reverse Linked List

Given the head of a singly linked list, reverse the list, and return the reversed list's head.

The linked list is represented as a space-separated sequence of integers on one line, followed by the number of nodes.

#### Example 1

Input

```
5
1 2 3 4 5
```

Output

```
5 4 3 2 1
```

Explanation: The list 1 -> 2 -> 3 -> 4 -> 5 becomes 5 -> 4 -> 3 -> 2 -> 1.

#### Example 2

Input

```
3
1 2 3
```

Output

```
3 2 1
```

#### Example 3

Input

```
2
1 2
```

Output

```
2 1
```

#### Constraints

- The number of nodes in the list is in the range `[0, 5000]`.
- `-5000 <= Node.val <= 5000`
